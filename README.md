# Backend NestJS - Google OAuth2

Trabajo práctico de backend desarrollado con NestJS.

## Tecnologías

- Node.js
- NestJS
- TypeScript
- PostgreSQL
- Prisma ORM
- Passport
- Google OAuth2
- JWT
- Jest

## Funcionalidades

- Autenticación mediante Google OAuth2.
- Registro automático de usuarios.
- Persistencia de usuarios en PostgreSQL.
- Control de duplicados por email.
- Vinculación de cuentas locales con Google.
- Generación de JWT.
- Protección de rutas privadas.
- Tests unitarios con Jest.

## Estructura principal

- AuthModule
- UsersModule
- DatabaseModule
